  2. On the General tab, choose the Authorization Code grant and add this Sign-In Redirect URL: {% if callback %}{{ callback }}{% else %}set the address of this tool under Settings first{% endif %}
  3. On the Scopes tab, keep openid, email and profile. To give roles by group, add a custom scope groups with a claim groups mapped to your group attribute - for Active Directory, a format_ad_groups claim transformation gives plain group names - and add groups to the scopes below.
  4. Copy the Issuer, Client ID and Client Secret from the Metadata tab into the form below, switch single sign-on on and save.

Provider

With groups set, every sign-in sets the global role: an administrator group gives administrator, a tenant administrator group gives tenant administrator, anything else user - the last enabled administrator is never demoted. Without groups, roles are set on the Users page. Access to each tenant is always granted on the Tenants page.

New accounts get the role user and no tenant access until it is granted. When off, only people who already have an account get in - on their first sign-in they are matched by e-mail.
